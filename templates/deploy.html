🚀 部署到公网

让全世界 AI Agent 都能调用你的天气 API

最简单 Railway — 5分钟上线

无需服务器，免费额度够用

1 把 weather_api 文件夹上传到 GitHub 公开仓库

2 打开 railway.app，用 GitHub 登录

3 点 New Project → Deploy from GitHub repo

4 选择你的 weather_api 仓库，Railway 自动部署

5 部署完成后会得到域名如 weather-api.up.railway.app

# 验证部署成功
curl https://你的域名.up.railway.app/health
# → {"status":"ok"}

# AI Agent 调用
curl https://你的域名.up.railway.app/v1/weather?city=张家界
# → HTTP 402 + 支付信息
中等 Render — 自动HTTPS

免费计划，自动免费SSL证书

1 注册 render.com

2 New Web Service → 连接 GitHub 仓库

3 设置：Runtime Python 3，Build pip install -r requirements.txt，Start python app.py

4 环境变量添加 PORT=10000（Render 自动分配端口）

专业 自有VPS — 完全掌控

阿里云/腾讯云/任何Linux服务器

# SSH 登录服务器后执行
git clone 你的仓库地址
cd weather_api
bash deploy.sh

然后用 nginx 反向代理 8080 端口到 80/443

📦 上传到 GitHub (必须)

Railway 和 Render 都需要 GitHub，先打包上传：

# 在 weather_api 目录下已有这些文件：
app.py              # 主程序 + x402中间件
requirements.txt    # Python依赖
start.sh           # 启动脚本
templates/         # HTML文档页面
test_x402_flow.py  # 端到端测试
demo_agent_flow.py # Agent视角演示
deploy.sh          # 一键部署

把整个 weather_api 文件夹 push 到 GitHub 新建仓库即可。

✅ 部署后验证
# 1. 健康检查
curl https://你的域名/health

# 2. 无支付请求 (应返回402)
curl https://你的域名/v1/weather?city=张家界

# 3. 模拟支付获取token
curl -X POST https://你的域名/v1/pay \
  -H "Content-Type: application/json" \
  -d '{"amount":0.01}'

# 4. 带token获取数据
curl -H "X-402-Payment-Token: 你的TOKEN" \
  "https://你的域名/v1/weather?city=张家界"
🔐 切换到真实支付 (可选)

部署成功后，在 Railway/Render 的环境变量里设置：

X402_MODE=live
X402_SECRET=你的随机密钥
RECIPIENT_ADDRESS=0x你的Coinbase钱包地址
