🔗 中国天气 API x402

为 AI 旅游规划 Agent 设计的付费天气接口

快速验证 (30秒)

curl 一键走完整流程
# 1. 无支付请求 → 402
curl -s {{ base_url }}/v1/weather?city=张家界&days=3

# 2. 模拟支付获取 token
curl -s -X POST {{ base_url }}/v1/pay \
  -H "Content-Type: application/json" \
  -d '{"amount":0.01}'

# 3. 带 token 重试 (复制上一步的 token)
curl -s -H "X-402-Payment-Token: 你的TOKEN" \
  "{{ base_url }}/v1/weather?city=张家界&days=3"

API 端点

端点方式付费说明
/v1/weatherGET$0.01城市天气预报 + 旅游建议
/v1/payPOST免费模拟支付获取 token (dev)
/v1/citiesGET免费支持的城市列表 (76个)
/healthGET免费服务健康检查

天气查询参数

参数类型必填说明
citystring是城市名 (中文)
daysint否预报天数 1-14 (默认7)

定价

方案价格说明
单城市 7 天$0.01基础查询
单城市 14 天$0.02深度预报
多城市批量$0.05行程规划

部署步骤

方案A: Railway (最简单，5分钟)
  1. 访问 railway.app 用 GitHub 登录
  2. New Project → Deploy from GitHub repo
  3. 把 weather_api 文件夹 push 到 GitHub
  4. 添加 start.sh 为启动命令
  5. 自动获得公网域名
方案B: 任何 VPS
cd weather_api
pip install -r requirements.txt
# 修改 X402_MODE = "live"
# 设置 export RECIPIENT_ADDRESS=你的钱包地址
nohup python app.py &
# 用 nginx 反向代理 8080 端口

切换到真实支付

修改 app.py 开头两行： 
X402_MODE = "live"                          # 改为 live
X402_SECRET = "你的强随机密钥"               # 改为随机串
RECIPIENT_ADDRESS = "0x你的Coinbase钱包地址"  # 真实地址
然后 /v1/pay 端点自动禁用，Agent 需走 Coinbase x402 facilitator 完成真实 USDC 支付。
